# Analise-de-DadosBrasileir-o

Backup completo do projeto de análise de dados do Brasileirão, incluindo backend, frontend, dados, documentação e arquivos de configuração.

## Estrutura

- `backend/`: API, processamento e testes.
- `frontend/`: aplicação web.
- `data/`: dados brutos, normalizados e snapshots.
- `docs/`: documentação do projeto.

Use `.env.example` como referência e mantenha valores reais de configuração em `.env`, que não deve ser commitado.
